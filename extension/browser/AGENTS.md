# L4 · Browser extension
> Seven real browser Tools with same-session evidence, explicit HITL and no legacy user-profile bridge.

## 地位
Optional native Plugin above independent integration/protocol/browser and platform/host/browser; SDK has no browser or storage policy.
## 逻辑
The real catalog retains browser_start/stop/navigate/action/snapshot/screenshot/status. Tools() returns those exact registered instances for trusted security assembly; copied names/objects never grant authority. Every operation binds actual native session/cwd/run/call, goes through Guard and prior activity plus same-authority browser_intent. Snapshots and real screenshot bytes are retained in session artifacts before small references are returned; browser_outcome and sanitized process lines stay in the same typed SQLite authority. Explicit browser_cleanup facts retain actual run-end/owner-close physical completion separately from journal errors and pending instance IDs. Close cancels run operations and joins the Tool gate, including approval/activity callbacks and outcome writes, before settling native ownership. A deadline retains the exact manager for retry; explicit owner Close permanently seals this Plugin. CleanupComplete reports process plus active Tool/fact completion independently of a Close error so an owning product never closes native facts while unfinished cleanup can still use them.
## 约束
Explicit approved immutable executable/cwd/temp-root/env/headless/proxy only. Process journal frames also redact that exact launch’s configured Env values, including unlabelled text/binary echoes; truncated prefixes are omitted. Model cannot select arbitrary executable/profile/argv or output filesystem path. No global discovery, old settings import, cookie/account inheritance, installation, child inheritance, automatic replay or direct image delivery. Except pure status, effects are conservatively Unknown/HITL. Tool scheduling is SerialGlobal/ManagesOwnTimeout; share the actual SDK ToolLockRegistry for cross-Agent coordination. Each run owns browsers and closes/removes its own private profiles even after normal completion, so this initial policy does not preserve cross-turn login/tab state.64 operations/64MiB artifact sources,512 process lines/16MiB canonical process journal, metadata≤4KiB, own operation≤1min. Extraction/encoding/scope/quality and heuristic readability limits are stated; no OCR/media understanding or full Reader Mode is claimed. CDP transport/Chrome resource and platform limitations remain those documented by protocol/host packages, not hidden by small model results. Product settings/UI and durable risk activity adaption are explicit consumers, not automatically enabled.
存储只消费本包按需组合的共享storage能力插口；会话/引用/DTO/错误从同一契约返回，不导入具体session.Repository或SQL实现。后端由上层程序/插件装配选择，组件不回落默认库、不downcast实现，不持有存储Close。
