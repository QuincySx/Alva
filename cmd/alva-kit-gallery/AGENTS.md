# L7 · Alva Kit 画廊入口
> 打开原生窗口，浏览组件库每个组件的全部设计变体。

## 地位
开发与设计审阅入口，不属于任何产品；不访问存储、网络、模型或会话。
## 逻辑
`--page <组件>`、`--dark`、`--narrow` 只设置初始状态；窗口内容是 `apps/ui/kit/gallery.App`。
## 约束
所有文件受 `desktop` build tag 控制；字体取自 kit 内嵌的设计字体。
## 业务域清单
| 文件 | 职责 |
|---|---|
| main.go | flags 到画廊状态（`prepare`）、字体注册与窗口 |
| main_test.go | 页面与外观选择、未知页与多余参数被拒绝 |
