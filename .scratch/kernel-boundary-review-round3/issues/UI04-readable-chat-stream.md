# UI04: 重做主聊天阅读流与 Markdown 呈现

**Priority:** P1
**Axis:** 用户最新 UI 重整需求 / 产品审查
**Origin:** 2026-09-11 用户“你好”真实会话及全 UI 反馈；HEAD `f9d0e57`
**Blocked by:** UI01、UI02、UI03
**Status:** ready-for-agent

## 问题与证据

用户真实“你好”会话：聊天顶部无条件展示执行时间线（hub-timeline.tsx:170）；用户/助手消息套着占整宽的高边框大卡片并标“用户消息/助手消息”；回答中的 **加粗** 和 - 列表直接作为文本显示。
主阅读轴让诊断图、重复角色标签、空隙与正文竞争。截图 evidence/native/user-hello.png；这不是仅样式偏好，当前还缺失消息内容的基本排版。

## 实现范围

主聊天保留自然消息流和紧凑工具活动。移出执行泳道到Inspector，并能从对应步骤定位过去；用户输入可适当分组，助手正文采用清晰排版而非层层卡片。
支持Markdown段落、列表、强调、链接、代码块与复制；流式更新保持阅读位置，可回看历史并提供回到底部。审批/失败/fallback就地简洁显示，详细诊断进入Inspector；不要重复呈现同一消息和事件摘要。

## 验收

- [ ] “你好”首屏以问题和完整可读回答为主，没有执行图/内部ID/技术记录数。
- [ ] Markdown示例正确渲染，代码块横向滚动不撑破阅读宽度；复制得到期望内容。
- [ ] 工具多次调用、流式长回答、取消、失败、审批、fallback和恢复历史均有明确紧凑状态。
- [ ] 用户向上阅读时新输出不强制拉回底部；对应诊断入口准确定位运行步骤。
