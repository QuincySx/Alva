## 已确认产品方向

类似 Codex 的 Agent 工作台，默认自研 ALVA，可选 Codex、Claude Code SDK、Pi；Provider 管理不同协议端点和调用来源，任务发起时可选真实兼容的引擎/模型/额度来源。启动入口明确区分“对话模式”和“项目模式”：对话不强制选择项目；项目关联仓库工作树，并聚合对应会话。不是把所有对话都强行项目化。

中央阅读区优先简单、完整：先展示全部用户可见的 AI 消息、工具调用/结果、审批和执行状态，暂不做信息折叠、摘要替代或把工具信息移出主阅读轴。这里的“全部”不包含密钥、隐藏推理、内部日志或安全策略禁止展示的数据，也不要求所有历史内容同时挂载 DOM。未来收拢只是呈现策略，不能丢掉权威记录。长会话滚动、流式更新、历史加载和切换性能是本轮核心交付。
