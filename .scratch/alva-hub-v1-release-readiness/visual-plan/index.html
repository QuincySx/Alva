Part III · Go / No-Go

七道发布闸门

G0–G6
G0Truth

commit、Engine 范围、版本、测试数和 artifact hash 与文档完全一致。

G1Runtime

每个 release Engine 有 packaged GUI fresh run；声称 resume 的 Engine 再有 restart/resume。

G2Continuity

六种 continuity failure 至少有自动化与 packaged 证据，且 fallback 可见、有限、可逆。

G3Durability

关键 persistence phase 的 crash/restart、schema migration 与 orphan repair 不破坏不变量。

G4Distribution

Developer ID、notarization、Gatekeeper、冷安装和覆盖升级通过；ad-hoc 不算发布签名。

G5Safety

secret redaction、权限不降级、owner-only 数据、依赖与正式 bundle 内容审计通过。

G6UX

最终签名包的键盘、焦点、中英文、窄窗口、VoiceOver 与 reduced-motion smoke 通过。
