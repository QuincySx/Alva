# ALVA Hub Cindy-Style Redesign Spec

## 目标

把 `alva-hub-gpui` 从“多个业务面板并排的控制台”重构成聊天优先产品：用户的大部分操作在同一条会话时间线内完成，项目和会话在左侧导航，终端、文件、审查、Inspector 等高级能力在右侧多标签工作台。

不追求 Cindy 像素级复制；追求相同的信息层级、交互节奏、空间利用和克制程度。

## 主壳

### 左栏

- 固定基准宽度 248 px，可折叠。
- 一级入口只保留：新建、自动化、插件、搜索。
- 项目是一级分组，会话是项目子项；运行中、未读和失败用单个状态点表达。
- 项目与会话的完整管理动作进入右键菜单；hover 只显示一个更多按钮。
- 底部固定账户、版本、远程连接和设置入口。

### 中央聊天

- 页面只保留一条主要阅读轴，正文最大宽度约 820 px。
- 用户消息、Agent 文本、工具活动、审批、错误、压缩和 handoff 都在同一时间线。
- 工具执行默认渲染为一行摘要：图标、状态、名称、耗时、展开箭头。
- 展开后显示参数摘要、进度、结果、错误和可定位资源；不跳转到独立“运行面板”。
- 空会话只显示品牌、新对话 Composer 和 4 个快速开始卡片。

### Composer

- 固定在聊天底部，使用一块 12–14 px 圆角的单体卡片。
- 第一行是可增长文本区；第二行从左到右为：附件/命令、权限、项目上下文、Agent、模型、语音、发送。
- 运行时发送按钮变为停止按钮，仍允许排队后续消息。
- 底部状态条显示工作区、上下文/预算、当前任务用量和进度，不在页面顶部堆状态卡。

### 右侧工作台

- 默认关闭，记住每个 HubSession 的打开状态和宽度。
- 可调整宽度，基准 520 px；支持多个可关闭标签。
- 第一批标签：文件、审查、Agent、Inspector、后台任务、资源、浏览器、终端。
- `Agent` 展示当前 HubSession 依赖的递归子 Agent 树。
- `Inspector` 是独立 Debug 工具，只对 ALVA session 提供完整事件；其他引擎能显示多少显示多少。
- Inspector 全局开关放在实验设置中，只控制显示，不改变运行语义。
- 标签内容可最大化或弹出到新窗口；关闭右栏不终止标签中的终端或后台任务。

## 新对话和项目

- 新建进入空白对话，不先弹全屏向导。
- Composer 右上角选择：纯对话、最近项目、选择其他项目文件夹。
- 选择文件夹即创建/复用项目上下文；不额外制造“项目创建表单”。
- Agent、模型和权限使用锚定菜单，搜索和当前选择始终可见。

## 自动化

- 首页优先显示现有自动化；为空时显示一个主按钮和模板分组。
- 创建使用单个模态表单：名称、执行方式、计划、生命周期、静默运行、前置检查、Prompt、项目、Agent、模型。
- Cron 编辑器提供常用预设和人类可读说明，不强迫用户直接写表达式。
- 模板点击后打开同一表单并预填，不创建任何对象，直到用户明确点击创建。

## 插件与技能

- 插件和技能是同一页面的两个标签。
- 已安装置顶；推荐插件使用两列卡片网格。
- 插件卡片提供详情、对话和配置；“对话”直接新建会话并预填插件 mention。
- 详情页统一包含：启用开关、版本/来源、配置、工具列表、权限和卸载/更新动作。
- 技能页显示名称、简介、来源和详情入口，并提供搜索与导入。

## 设置

- 使用独立设置路由：左侧分类目录，右侧单页内容。
- 分类首批包含：通用、个性化、模型与引擎、用量、快捷键、任务导入、远程、工具、自动化、实验、帮助、关于。
- 设置项统一使用有标题和说明的行；控件靠右，分组使用低对比度卡片。
- 外观允许主题、界面字体、代码字体和字号调整。
- 实验页放 Inspector 显示开关和仍未稳定的功能；不再保留 `Dev mode` 产品概念。

## 视觉规则

- 颜色：一个低饱和背景、一个卡片层、一个边框层、一个强调色；不使用多色状态面板。
- 圆角：输入/卡片 10–14 px，胶囊 16–20 px；同一层级保持一致。
- 边框：1 px 低对比边框替代大阴影。
- 字体：正文 14 px，辅助 12 px，页面标题 22–24 px；行高优先保证可读性。
- 间距：4/8/12/16/24/32 的固定步长。
- 动画：菜单 100–140 ms，抽屉 160–220 ms；禁止大面积弹跳和无意义光效。
- 图标按钮必须有 Tooltip；加载使用组件库 Spinner/Skeleton，不使用文本闪烁。

## gpui-component 映射

- 左栏：`Sidebar`、`SidebarMenu`、`SidebarMenuItem`、`Avatar`、`Tag`。
- 页面标签：`TabBar`。
- 菜单：`DropdownMenu` / `PopupMenu`。
- Composer 与搜索：`Input` / `TextArea`、`Button`、`Tooltip`。
- 详情与设置：`Collapsible`、`Checkbox`、`Select`、`Switch`、`Slider`。
- 运行态：`Spinner`、`Skeleton`、`Tag`。
- 设置：`Settings` / `SettingPage` / `SettingGroup` / `SettingItem` / `SettingField`。
- 弹窗与抽屉：`Dialog` / `Sheet`。

## 组件优先实现顺序

页面不得直接从线稿跳到大段布局代码。固定顺序如下：

1. 从 67 张逐状态线稿中提取重复结构和交互状态。
2. 为每个结构选择现有 `gpui-component` 基础组件。
3. 只在基础组件之上封装 Hub 领域组件，不复制 Button、Input、Tab、Settings、Dock、Menu 的行为。
4. 先建立可单独渲染的组件目录，再用组件拼装聊天、自动化、插件、设置和右侧工作台。
5. 每拼完一个状态，就与同名线稿和原截图并排验收。

首批 Hub 领域组件：

- `HubSurfaceHeader`：页面标题、说明与右侧操作。
- `HubEmptyState`：图标、标题、说明和主操作。
- `HubTemplateCard`：自动化与快速开始模板。
- `HubExtensionCard`：插件、技能和引擎卡片。
- `HubActivityRow`：聊天中的可折叠运行活动。
- `HubComposer`：输入、项目、权限、Agent、模型和发送。
- `HubToolPlaceholder`：右侧标签统一空状态。
- `HubSettings`：直接组合组件库 `Settings` 体系。

组件覆盖门槛：

- 页面级导航、菜单、标签、设置、弹窗、抽屉和 Dock 必须直接使用组件库能力。
- 图标按钮必须使用 `Button::tooltip`；禁止再手搓 tooltip。
- 设置页面禁止再手搓左栏和设置行。
- 自动化和插件卡片只能由领域组件输出，页面不得复制卡片边框、圆角和间距。
- 裸 `div()` 仅用于文字排版和无法由组件库表达的局部布局，不再作为交互控件。

禁止只引入依赖后继续用大量裸 `div()` 仿造组件。

## 验收

1. 新建会话后可在一个 Composer 内完成项目、引擎、模型和权限选择。
2. ALVA、Claude、Codex 的用户可见消息都进入同一聊天时间线。
3. 工具调用和审批默认折叠，可原地展开，不强制切换页面。
4. 右栏可同时打开至少三个标签，并记住每个会话的标签与宽度。
5. 文件、审查、Agent、Inspector、终端五个核心标签可用；其余可先提供明确空状态。
6. 插件对话可预填 mention；自动化模板可预填表单但不会自动创建。
7. 设置页覆盖主题、模型与引擎、快捷键、工具、自动化和实验。
8. 主要控件来自 gpui-component；视觉审计不再出现大面积手搓状态卡。
9. 1440×900、1280×800 和窄窗口下不遮挡 Composer，右栏可自动关闭。
10. 旧 Tauri / App 目录在 GPUI 功能和视觉验收全部通过并获得明确确认前不删除。
