        ┌── [OVERLAY: CronSchedulePicker - Width: 340px] ────────────────┐
        │ ⏱ 配置执行时间与调度规则                                       │
        ├────────────────────────────────────────────────────────────────┤

        │ 具体时间:  小时: [ 02 时 ▾ ]   分钟: [ 00 分 ▾ ]  (UTC+8)      │

        │                                               [重置]   [✓ 确认]│
        └────────────────────────────────────────────────────────────────┘
