## 1. 项目与会话右键上下文菜单 (Context Menus)

### 1.1 项目级右键菜单 (Project Menu)
```text
触发方式：在侧栏项目标题 (如 `📁 alva-agent`) 上点击右键或 "[⋯]"

        ┌── [OVERLAY: ProjectContextMenu - Width: 220px] ────────────────┐
        │ ✏️  重命名项目 (Rename)                                         │
        │ 📌 置顶项目到顶部 (Pin to Top)                                 │
        ├────────────────────────────────────────────────────────────────┤
        │ 🔍 在此项目中搜索任务…                               [⇧⌘F]     │
        │ 📁 在访达 / Finder 中打开                                      │
        │ 💻 在 VSCode / Zed 中打开                                      │
        ├────────────────────────────────────────────────────────────────┤
        │ 🔗 复制项目深度链接                                            │
        │ 🔄 同步本地 Codex / Claude 历史任务                            │
        ├────────────────────────────────────────────────────────────────┤
        │ 📦 归档该项目所有任务                                          │
        │ 🗑  从侧边栏移除项目                                            │
        └────────────────────────────────────────────────────────────────┘
```

### 1.2 会话级右键菜单 (Session Menu)
```text
触发方式：在侧栏会话条目或顶部 Header 标题右侧点击 "[⋯]"

        ┌── [OVERLAY: SessionContextMenu - Width: 220px] ────────────────┐
        │ 📌 置顶此会话 (Pin Session)                                    │
        │ ✏️  重命名任务标题 (Rename)                                     │
        │ 📁 移动到其他项目 (Move to Project)                          › │
        ├────────────────────────────────────────────────────────────────┤
        │ ◫ 在独立新窗口中打开 (Open in Window)                          │
        │ 🔗 复制任务链接                                                │
        │ 📸 分享为图片长图 (Share as Image)…                            │
        │ 📤 导出对话记录 (Markdown / JSONL)…                            │
        ├────────────────────────────────────────────────────────────────┤
        │ 📦 归档此任务 (Archive)                                        │
        │ 🗑  删除此任务 (Delete)                                         │
        └────────────────────────────────────────────────────────────────┘
```
