# Adapter boundary probe
> 使用真实 Codex/Pi adapter.execute 的独立边界反例。

## 地位
独立 Cargo 工程，本地临时假 CLI，无网络。
## 逻辑
先健康成功对照，再原生终态后非法 UTF8，并验证真实错误先于重试决策的 Pi 序列。
## 约束
不强制选择忽略尾部还是报读取错误的策略；最终事件必须一致。
## 业务域清单
| 名称 | 文件/子目录 | 职责 |
|---|---|---|
| 探针 | main.rs | 2 个健康对照、2 个终态一致性反例、1 个 Pi 重试反例 |
| 依赖 | Cargo.toml / Cargo.lock | 本地产品依赖与固定解析 |
