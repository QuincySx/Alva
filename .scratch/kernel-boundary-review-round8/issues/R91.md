# R91: Desktop Stop 只在真实结束后结算终态

Priority: P1
Status: open
Baseline: c8aca9c8

## 责任范围与证据

`crates/alva-hub-desktop/src/main.rs:1249–1265`，必要的共享 run 结束通知/取消事实接口。

Desktop 在 await cancel 前已 record_attempt_cancelled，cancel Err 仍留下虚假取消事实；成功 ack 后立即广播 Interrupted，但实际流未必结束。对应 UI 文案（web/src/i18n.tsx:1095）声称运行时已退出、可安全继续，此时还可能收到输出或 Completed。

静态确认。旧 R51/R65 明确只检查 HTTP Stop，本卡补 Desktop 的事实/终态语义；R86 只处理失败后审批路由丢失，不重复。

## 有限验收

- cancel Err 时零成功取消事实，实际运行仍可控制。
- cancel ack 后保持流挂起，只呈现停止中；直到真实结束才结算。
- 自然 Completed 不再额外追加相互冲突的 Interrupted；失败/强杀恰好一次正确终态。
- 取消事实和结算绑定原 attempt，与 R77/R80 的代际保护一致。
- 共享 R86 的 fake engine 夹具可以，但独立断言取消事实与终态，不只测审批。
- 不向 kernel 添加 Desktop 状态；遵守目录规范；记录真实测试、commit。
