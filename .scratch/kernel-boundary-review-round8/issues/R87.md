# R87: 用户 Stop 导致的强杀不能触发自动 fallback

Priority: P1
Status: open
Baseline: c8aca9c8（2026-09-17 复审）

## 责任范围

crates/alva-hub-desktop/src/run.rs 与取消事实共享契约；HTTP/Desktop 共同消费者

## 问题与证据

位置：crates/alva-engine-adapter-claude/src/adapter.rs:391–428；crates/alva-hub-desktop/src/failure.rs:128–134；run.rs:301,1022。

Claude Full cancel grace 超时发出 'claude bridge did not stop within cancel grace; killed'；真实 classifier 将其归 Crash，run 的 fallback loop 没有用户停止检查，于是继续启动已授权后继引擎。

证据状态：从当前 Rust 源码编译执行分类器：Crash, triggers_fallback=true；整个 Stop→fallback 组合尚未动态运行。见 server-control-probe.mjs。

## 有限验收

配置授权 fallback，Stop ack 后触发取消 grace 强杀，后继 engine.execute 次数必须为 0；没有 Stop 的真实 crash 仍继续 fallback。取消意图绑定 turn/attempt，优先于故障连续运行策略；不要只改一条错误文案或全局禁用 Crash fallback。

先加能暴露本卡问题的反例，再修复；独立逻辑提交。记录实际命令、结果与 commit，不把未执行写成通过。遵守根/目录 AGENTS 与分形文档；不得回退其他 agent 的 dirty work。
