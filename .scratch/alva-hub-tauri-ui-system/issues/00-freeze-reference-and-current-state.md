# 00 Freeze Reference and Current State

## 目标

冻结 67 张 Cindy 截图、67 张线稿、7 张总线稿和当前 Hub 截图，建立不可混淆的验收基线。

## 工作

- 为每个页面族建立 reference/current/target 三联索引；
- 标记线稿中遗留的 GPUI 名称，不把技术栈文字当产品要求；
- 保存 1440×900、1280×800、窄窗口当前截图；
- 记录当前未提交 UI 改动，不混入功能开发。

## 验收

- 67 个状态都有唯一 ID；
- 七个页面族均可从索引跳到原图、线稿和当前截图；
- 没有删除或覆盖用户保存的参考文件。
