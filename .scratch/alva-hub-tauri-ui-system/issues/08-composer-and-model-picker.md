# 08 Composer and Model Picker

## 目标

按 02–07、51–52 线稿完成 Composer 和模型选择体验。

## 工作

- ComposerToolbar、ComposerStatus、运行/停止状态；
- Context、Permission、Agent、Model 四类锚定菜单；
- ModelPicker 的 engine tabs、search、route list、detail；
- 可用/不可用分组和不可用原因；
- model/provider/billing 技术信息渐进披露；
- popup 高度按内容自适应，长列表内部滚动；
- fixture 通过后连接真实模型目录与会话创建。

## 验收

- 新对话可在 Composer 内完成所有选择；
- 不可用模型可理解原因但无法误选；
- 一条和二十条模型都没有大块空白或溢出；
- 键盘完成搜索、切 tab、选择和关闭；
- fixture 与真实模型选择均通过。
