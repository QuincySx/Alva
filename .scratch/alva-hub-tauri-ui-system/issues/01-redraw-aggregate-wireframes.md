# 01 Redraw Aggregate Wireframes

## 目标

保留 67 张逐状态线稿，按正式规范重新绘制七张统一比例的页面总层架。

## 工作

- 使用 `docs/ALVA-HUB-UI-WIREFRAMES.md` 的命名和绘制规则；
- 标注 AppFrame、Region、Surface、Control 和 Domain component；
- 标注宽度、Dock、Scroll owner、Overlay trigger 与 close path；
- 为发生关系变化的页面补充 desktop-docked 与 narrow-overlay 帧；
- 将每个总层架链接回对应的逐状态线稿。

## 验收

- 七张总层架使用统一画布、比例和符号；
- 每个视觉区域只有一个尺寸和滚动所有者；
- 没有把 Cindy 品牌参数误写成 ALVA 组件规则；
- Chat、Composer、Workbench、Settings 的区域归属无歧义。
