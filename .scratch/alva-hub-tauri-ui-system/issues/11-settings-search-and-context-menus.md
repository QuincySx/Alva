# 11 Settings, Search, and Context Menus

## 目标

按 14–28、53–58、65 线稿完成设置、全局搜索和项目/会话菜单。

## 工作

- SettingsNav、SettingsPage、SettingsGroup、SettingsRow；
- 模型与引擎、用量、工具、自动化、实验和 Inspector 开关；
- SearchSurface 与结果分组；
- ProjectMenu、SessionMenu、FolderPicker、危险确认；
- fixture 通过后接入真实设置、搜索和文件选择。

- 设置页不自建第二套控件和 section；
- 搜索结果与主导航共享 Row 组件；
- 危险操作有明确二次确认；
- 菜单位置、宽度和关闭路径与线稿一致；
- fixture 和真实设置/搜索流程均通过。
