# ALVA Hub target wireframes

These seven SVGs redraw the Cindy-derived aggregate hierarchy for the Tauri
product. They complement, rather than replace, the 67 source screenshots and
67 state lineworks in `.scratch/cindy-ui-reference/`.

Every drawing labels region ownership, the single scroll owner, docked areas,
and overlay relationships. Playwright screenshots with matching numeric names
live under `crates/alva-hub-desktop/web/tests/visual.spec.ts-snapshots/`.
