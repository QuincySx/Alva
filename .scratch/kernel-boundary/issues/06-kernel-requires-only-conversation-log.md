# 06: 内核只认对话记录

**What to build:** 内核循环收窄到只要求**对话记录**。收窄之后，一个二十行的内存实现就能把
内核跑起来——这正是"极其通用的内核"该有的门槛，也是 wasm worker 与第三方 SDK 用户
真正需要的东西。

顺带把这个巨型契约积压的合约谎言一并清掉（2026-07-18 review 第 11 条）：

- 文档承诺运行时会在若干时机刷盘，**内核实际一次都没调**。要么真调，要么把承诺从文档删掉。
- 文档要求关闭之后其他操作返回错误，但**大量读写方法根本没有返回错误的能力**，
  类型层面兑现不了。拆开后对话记录的方法一律可失败。
- 可监听的内存实现在分配序号后释放锁再异步广播，并发追加可能**先播 2 后播 1**；
  广播还持着监听者读锁串行等待，一个慢监听者会卡住追加与订阅。
