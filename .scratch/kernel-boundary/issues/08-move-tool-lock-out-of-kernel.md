# 08: 资源锁搬出内核

**What to build:** 内核里住着一张进程级的工具资源锁表，供多个 agent 与子 agent 共享。
按判据它不该在那儿——**一个只会翻译文本的单 agent 不需要跨 agent 资源锁**。
它是多 agent 协作的机制，属于装配层。

搬完之后内核不再认识"多个 agent 共享同一份资源"这个概念；
调度用到的词汇（资源键、锁模式、执行模式）留在契约层，运行期的那张表搬走。
