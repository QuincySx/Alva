# 12: 新建 agent 契约层（expand）

**What to build:** 内核契约层现在同时装着两类东西：**循环真正需要的**（消息、工具、模型、
取消、错误）和 **agent 产品概念**（任务、作用域、派生、会话记录、阶段、分析埋点）。
后者有真实用途，但它们描述的是"我们这一类 agent 产品长什么样"，不是"循环怎么转"——
第三方拿内核去搭一个完全不同形态的 agent 时，可以整层不用。

拆出一个新的 agent 契约层 crate，位于内核契约之上、SDK 装配之下。
