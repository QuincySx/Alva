# 09: 内存会话实现搬出内核

**What to build:** 内核里躺着两个具体的内存会话后端，一千五百行。契约该在内核，
**实现不该**——内核带着默认实现会让"内核 = 无观点的机制"这句话失效。

搬到 **SDK 装配层**（不是内置扩展库）：走 SDK 入口的用户不装任何扩展也需要一个能跑的会话，
所以默认实现必须在装配层够得着的地方。
