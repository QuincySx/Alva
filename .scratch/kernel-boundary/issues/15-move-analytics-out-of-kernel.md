# 15: 埋点移出内核

**What to build:** 内核循环现在会主动上报一条 LLM 分析埋点。按判据它不该在那儿——
**一个只会翻译文本的 agent 不需要埋点也能跑**。

搬走之前先看清三个事实，它们说明这次搬家不丢任何数据：

1. **成本从来没采集过。** 内核上报的成本字段是**写死的零**。
   全仓唯一真实的成本数字来自 Claude 引擎自己在输出里报的值——
   算成本需要 provider 价目表，而内核不知道钱。
2. **token 与耗时已经发过一遍了。** 就在上报埋点的上方十行，内核已经把输入输出 token、
   缓存读写、缓存命中结果作为一条运行期事件发进了会话流。埋点是**同一份数据的第二份拷贝**。
3. **工具埋点早就由中间件采集。** 分析插件本身就是一个中间件，
   已经在用工具调用的前置 / 后置钩子采集。**LLM 埋点由内核直发是唯一的例外**，
   是不一致，不是必需。中间件契约上的 LLM 钩子一直都在，只是没实现。

所以搬家 = 补上分析中间件的 LLM 钩子，让两条线一致。

**这两件事必须在同一次提交里**——先删后补会留下一个丢埋点的 commit。
