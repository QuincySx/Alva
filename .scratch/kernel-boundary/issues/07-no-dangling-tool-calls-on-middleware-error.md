# 07: 工具批出错不再留下悬空调用

**What to build:** 模型已经发出一批工具调用、内核已经把它们提交进历史之后，
如果某个中间件在前置 / 环绕 / 后置阶段普通报错，内核会直接返回，
**当前这个和剩下那些调用都拿不到结果**。下一次请求带着这段历史发给 provider，
部分厂商会直接拒绝整段对话。

修完之后：中间件出错时，这一批里每一个已提交的调用都有对应结果（哪怕是错误结果），
历史永远不会带着悬空调用离开内核。
