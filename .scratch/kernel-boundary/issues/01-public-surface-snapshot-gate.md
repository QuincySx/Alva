# 01: 公开符号快照闸 + Registrar 准入规则

**What to build:** 内核契约层与 SDK 装配层的公开符号被快照到版本库里，CI 在每次改动时比对。
任何人往这两层加、删、改一个公开符号，CI 都会把 diff 摆到面前，要求人工确认后更新快照。
这是本次重构的第一道工序——之后每一刀的破坏面都由它记录，也是这条巨型分支的进度条。

同时把 `Registrar` 的准入规则写下来：它只接受"贡献"类方法（注册工具、中间件、提示词片段、
命令、服务），**不再新增"读取"类方法**（想读运行期状态去 bus）。现有的三个只读方法是历史欠账，
保留但不扩大。这条规则由同一个快照闸执行，不另写 lint。

**Blocked by:** 无（可立即开始）
