# 17: 第五个引擎能被构造出来

**What to build:** 引擎自述机制（声明自己支持哪些权限档、走什么 provider 协议、
需要装什么二进制）已经建好，产品也已经改成查自述而不是查名字——**但只对"第五个引擎"生效**。
四个内建引擎仍然走引擎名字面量的分支提前返回，而第五个引擎**根本构造不出来**：
装配函数是一串硬编码的分支，注册表是三个字符串字面量的匹配。

结果是这条 seam 只被合成测试覆盖，自述机制头部那句自我要求——
"任何产品都不该需要知道引擎的名字"——被它正下方的代码违反着。

这张票收口：引擎构造走注册表，权限、就绪检查、装配三处**不再出现任何引擎名字面量**。

进程内引擎（不需要外部二进制、需要 provider 配置）保留为一个**收窄的特例**：
"不需要二进制"这件事由自述里的既有字段表达，provider 配置的特判收回引擎自己的声明里，
不再由产品特判。

**Blocked by:** 无（可立即开始）
