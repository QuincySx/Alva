## 责任范围与问题

`crates/alva-hub-core/src/runtime.rs:997`（审查 HEAD `5290e033`）。旧 cancel await 后返回 Unsupported，按 product id abandon 会删除已经运行的新轮，新轮变 Failed。

## 执行记录

- commit: `fix(hub-core): stale cancel results must not abandon a newer generation (R63)`
- 复现（修复前）：审查证据工程 `cargo run --offline --manifest-path .scratch/kernel-boundary-review-round6/evidence/core/Cargo.toml --bin stale_cancel` → FAIL，`fresh turn status: Failed; live=false`（预期 Running）。
- 根因与修复：`cancel()` 在 await 引擎结果前未固定目标身份，返回 Unsupported 后无条件 `abandon`（按 product id 无差别释放当前认领者）。改为：
  - `abandon` 主体抽为 `abandon_locked`（调用方持 sessions 写锁）；
  - 新增 `abandon_targeted` + `ClaimTarget`（live 路径按 `RunHandle.generation`、回退路径按 `claim_seq`），校验与释放同处一次写锁持有内，多线程下无"校验后新 claim 插入"窗口；
  - `cancel()` 两条路径均在 await 前捕获目标身份（`my_generation` / `my_claim_seq`），Unsupported 返回后仅当目标仍是当前认领者才释放；`abandon` 公开签名不变。
- 验收对照（gate 全部确定性，无 sleep 断言）：
  - `stale_cancel_result_must_not_abort_new_generation`：旧 cancel pending→旧 Completed→新 Started→旧 Unsupported → 新轮仍 Running、`has_live_run=true`；随后对当前代际的真实 cancel 仍能落地（Failed + 无 live run）。
  - `stale_fallback_cancel_must_not_release_new_claim`：恢复会话（无 live run）cancel 停在引擎 gate，新 execute 认领后旧 Unsupported 返回不释放新 claim。

  - `cargo test --offline -p alva-hub-core --lib` → 42/42 PASS（原 40 + 新 2）。
  - 审查探针 `stale_cancel` 复跑输出 `fresh turn status: Running; live=true`。
