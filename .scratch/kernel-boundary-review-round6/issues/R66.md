## 执行记录

- commit: `fix(hub-desktop): recycle the published ActiveHubs entry on synchronous start failure (R66)`
- 复现（静态路径 + 新测试）：`execute_turn` 在 `hub.execute` 前 insert sink；同步 execute Err 早返回绕过尾部 remove——失败会话留下无运行的 Hub。审查探针 `server-projection.rs` 的路径与源码核对一致（未重复其 Cargo 锁等待问题）。

- 验收对照：
  - 正式 `run_persisted_with_target` 注入同步 execute Err（SyncFailEngine）→ 返回后 sink 为空，turn 标记 failed。
  - 后继轮正常认领同一 session、发布并在结束时清理（FakeEngine Started+Completed）。
  - 正常/取消路径保留：既有 `live_hub_is_published_while_running_and_removed_at_end`（含通过 hub 的 cancel 路径）继续通过。
