## 执行记录

- commit: `fix(hub-server): settle stop cancellation at real stream end with per-turn markers (R65)`
- 实现（`crates/alva-hub-server/src/main.rs`）：
  - **真实结束信号**：移除 projector 内对任何 terminal TimelineStatus 的取消结算（fatal Error 的 Failed 不再被当成流结束）。取消结算移到 run handler 的 `outcome_fut` 之后：消费 `stopping` marker（恰好一次），仅当引擎未自然完成（`run_completed_normally` 原子标志，由 projector 在 Completed 投影时置位）时追加唯一的 Interrupted；引擎自然完成（延迟 Completed）的取消只保留 Completed 终态。
  - **代际隔离**：run 开始时清理同 session 残留 marker；stop handler 在 cancel ack → 持久化取消事实 → 插入 marker 后复查 `active_hubs`，run 已结束（终态抢在 ack 前落地）则丢弃 marker，不泄漏到下一轮。
  - **持久化不静默**：取消事实改在 cancel 成功后立刻 `record_attempt_cancelled`（session 仍 running 是该 API 唯一能成功的窗口；run 结束时 finish_turn 已置终态，原先结算处的调用恒失败且被 `let _ =` 吞掉），失败以 500 上抛。
  - **测试接缝**：`build_app` 从 main 抽出；AppState 增加 `#[cfg(test)] test_engine_factory`，真实 Axum 监听 127.0.0.1:0，SSE 用原生 TcpStream 读取。
- 验收对照（全部为真实 HTTP/SSE 集成，gate 确定性，无 sleep 断言）：
  - `failed_cancel_records_nothing_and_run_completes`：cancel Err → stop 500 携带错误、无取消事实（`attempt_cancelled` 存储断言）、无 waiting/Interrupted 投影，run 正常完成。→"cancel Err 不记取消"。
  - `stop_acked_delayed_natural_completion_projects_completed_only`：ack 后流被 gate 住时无任何终态（保持停止中）；延迟自然完成后终态只有 Completed、零 Interrupted。→"ack 后延迟 Completed 保持停止中"+"终态只投影一个正确状态"。
  - `stop_acked_error_then_completed_projects_single_terminal`：Error 后流未结束不发取消终态；结束后恰好一个 Interrupted 且在 Failed 之后。→"Error 后尚未结束不发取消终态"。
  - `stop_acked_killed_stream_settles_interrupted_once_at_real_end`：取消截断（EOF 无终态）在真实流结束时结算恰好一个 Interrupted。
  - `terminal_before_ack_leaves_no_marker_for_next_turn`：终态抢在 ack 前 → 迟到 stop 被诚实拒绝；同 session 下一轮两个 completed、零取消残留。
