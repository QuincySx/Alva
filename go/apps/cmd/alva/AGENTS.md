# L6 · alva
> Safe CLI reference entry for the Go harness, not a Hub compatibility frontend.

## 地位
Consumes harness and platform/host directly, independent of EngineRuntime, MyGo, React and Rust binaries.
## 逻辑
No arguments or --demo executes a deterministic local Tool roundtrip. --live requires explicit full endpoint/model plus prompt or --repl; --provider selects openai_chat/openai_responses/anthropic/gemini through the same provider.Build factory on native and WASM paths. Optional API key uses explicit --api-key-stdin or separate granted regular/pipe --api-key-fd3..10, never argv/environment/old configuration. Stdin key reads use shared bounded/cancellable secretinput; an open pipe is not a shutdown blocker. --data-dir explicitly opens private native SQLite; an omitted --session creates a new opaque Go session, while --session opens only an existing one. --sessions and --history/--search read bounded metadata without constructing an Agent. Attachments are original bytes plus references, never automatic prompt bodies. --memory explicitly enables the persistent same-name memory Plugin only with live/workspace/data-dir; namespace is derived from the trusted canonical CLI workspace, not model input. Only local no-op embeddings are configured. --permission-mode chooses ask/accept_edits/plan; noninteractive Ask fails closed. Explicit --repl reuses the same direct harness/session and installs real exact-request-ID once-only approval input, serial across simultaneous requests; it never grants future/unknown tool rights. Empty REPL does not submit Hello or call a model, /session /help /quit remain local. Initial attachments require an explicit --prompt and are only sent once as references; WASM stays one-shot. Native stdin uses the Darwin/Linux sole-reader poll path or Windows regular-file/pipe PeekNamedPipe path, ≤32KiB/line and1024 lines/1MiB, without closing borrowed stdin or detached read goroutines.

`--sandbox wasm --wasm-module PATH --workspace HOST --grant HOST=/work` executes the actual Go WASIp1 SDK worker, not a native fallback. No bundled binary is discovered/downloaded. Each grant is explicit; Ask/Plan force host read-only, accept_edits permits writes only to non-readonly grants. Guest file refs are volatile; with --data-dir, native attachment/history refs proxy read-only through the actual owner/session authority, never a database mount or full-history prompt. Complete protocol IO/guest audit is framed, known-marker sanitized then retained as native artifact segments and small typed extension references; without --data-dir the bounded journal is explicitly volatile. Native user/final conversation facts and job intent/outcome remain distinct from untrusted guest audit. Model/IO/approval failure does not replay.
## 约束
额外--api-key-file仅只读打开显式已有owner-only regular文件（拒绝symlink/hardlink），与stdin/fd互斥；Windows明确拒绝Unix fd3..10，不将CRT fd当作HANDLE关闭。原始凭据不进参数、环境或输出，文件不创建/修改或被发现。
No automatic network start in demo or metadata operations, no provider credential discovery or legacy import. Persistence is opt-in; no old product data is overwritten. Uploads allow 20 MiB/file and 40 MiB/eight files per turn, reject sensitive paths/symlinks and say no compression/frame extraction/understanding occurred. --workspace supplies execution context and guarded file tools for live runs, not shell/network authority; only explicit accept_edits relaxes ordinary write approval, never unknown effects. Memory registration itself never scans/extracts/writes project notes. Unknown flags fail. Missing deltas recover from the actual snapshot, never model replay. AfterModel may replace streamed drafts/remove tool prefaces: divergence prints an explicit committed-response correction, never silently treating draft as final. Slow/expired observation resubscribes from high-water; successful terminal cannot truncate stdout. C0/C1 model terminal controls use shared terminaltext at display boundaries; raw facts/tool arguments remain unchanged. Short writes are failures. Signals Stop and wait at most five seconds, reporting timeout without claiming exit. Native repository is closed only after owned execution cleanup.

WASM deadline includes cold compilation; linear memory, exchanges, IO, model tokens/calls and fetch domains are host enforced. --wasm-fuel 1..1e12 enables version-1 Core V2 basic-block charging; 0 explicitly leaves only deadline/memory/IO limits. The original and rewritten binaries are separately validated; fuel excludes host callback time and dynamic bulk-memory byte work. --wasm-scripts explicitly delegates the isolated QuickJS capability using the same guest file/fetch grants. The worker and script share fuel and the total linear-memory ceiling; each script additionally has its own 10s deadline/32MiB tracked heap/512KiB soft C stack. Ordinary script errors preserve partial evidence and leave the Agent usable. No OS process sandbox is claimed. Ask/Plan write failure is not per-tool ask/elevation. Host shell is absent by default; --dangerously-allow-host-shell AND --approval-stdin/--approval-tty are both required, then EACH request needs a fresh exact challenge. --approval-stdin conflicts with --api-key-stdin. Approval reads are bounded/cancellable without detached readers. Plan forbids shell. The approved native child receives a pinned directory FD, fchdirs in its own trampoline and execs /bin/sh; the parent cwd never changes and the display HostPath is never execution authority. This shell is explicitly OUTSIDE WASM and may access other host resources. Only Darwin/Linux are implemented, others fail closed.
